# Networking Lab
Networking lab exercises, practicals, reports, and hands-on work covering computer networking fundamentals using Ubuntu Linux.
This repository contains my networking practicals, assignments, reports, and hands-on exercises.

The purpose of this repository is to build a strong foundation in computer networking and understand how networking concepts are related to cybersecurity.

## 🐧 Operating System

The practical work in this repository is performed using:

- Ubuntu Linux

Since some networking assignments use Windows commands, Linux equivalents are used where required.

| Windows | Ubuntu/Linux |
|---|---|
| `ipconfig` | `ip addr` |
| `tracert` | `traceroute` |
| `ping` | `ping` |

## 📚 Topics Covered

- Computer Networks Fundamentals
- LAN and WAN
- Client and Server
- Switches and Routers
- Firewalls
- IP Addresses
- MAC Addresses
- Default Gateway
- DNS
- Network Troubleshooting
- Network Connectivity Testing
- Traceroute
